# 开发日志 — 2026-07-30 15:37

今日目标
修复战斗系统全部 P0 级 Bug，使核心战斗循环稳定运行。

已完成（7个P0 + 3个架构优化）

1. AP 系统修复

BattleInputHandler 中 TrySpendAP 前置，AP 耗尽后点击地面不再能移动。
TrySpendCurrentUnitAP 改用 TryGetValue + 空判，消除崩溃风险。
新单位动态入战时调用 ResetAP()，修复 AP=0 → 无限 EndTurn → 队列死循环。
2. 战斗状态切换完善

StartBattle：遍历参战单位强制 StopMove()，清理入战前残留的移动脏状态（isMoving 卡 true）。
EndBattle：恢复 CharacterMoveControl.enabled 和 ClickSelector.enabled。
CharacterMoveControl 新增 allowFreeMove 标志，战斗中仅锁输入、保留距离检测在线。
3. NavMesh 移动完善

NavMeshMoveCtrl 新增 Update()，通过 remainingDistance ≤ 0.05 检测终点到达，不再依赖外部调用 CheckMoveDistance。
4. 动画驱动伤害判定（Animation Event）

BaseAniCtrl 新增 AttackHitTriggered 事件 + OnAttackHit() 方法，由 Animation Event 触发。
EnemyAI 订阅击打事件，HandleAttackHit 在动画击打帧精确发送伤害。
新建 PlayerAttackHandler 组件，玩家攻击也统一走 Animation Event 路径，附带 EndAttackRoutine 协程收尾。
Animator Controller：取消 Idle → Attack 的 "Has Exit Time"，消除退出延迟导致动画跳过。
5. 敌人 AI 行为修复

CheckMoving 删除 apManager.currentAP >= 2 检查，职责收窄——只检测范围。
DoMove 终点改为 attackRange × 0.8，避免 NavMeshAgent 碰撞体导致停在攻击范围边缘卡阈值。
测试验证
玩家 AP 耗尽后无法移动
敌人正常寻路 → 进入范围 → 攻击 → 扣血 → 回合切换
动态入战单位正常加入队列并参与回合循环
攻击伤害在动画"砍中帧"触发，时序同步
战斗结束后恢复自由移动
